
Langage d'assembleur 

    - plus bas niveau que C, C++ ou même Fortran 
    - Répresentation <<lisible>> su langage machine 
    - un langage pour chaque processeur 
    - Communication plus fine avec l'os

    - Historique :
        - Invention auw alentours de 1950
        - Premier programme ecrit en 1954(IBM 701)
        - outils incontournables (ex : GCC en 1987)

    - Quelques termes : 
        - assembleur 
        - assemblage / désassemblage  
        - langage d'assembleur (ou langage d'assemblage)

    - Quelques syntaxes : 
        - Intel 
        - AT&T

    - Jeu d'instructions (opérations élémentaires) : 
        - manipulations en mémoire 
        - calculs arithmetiques 
        - comparaisons 
        - sauts, appels 

    - Pour qui et pourquoi ? 
        - optimisations sur un programme existant 
        - architectures specifiques 
        - hacking, analyse, retro-ingeniérie
        - curiosité d'apprendre...

    - Mais attention !
        - plus de code qu'un langage de plus haut niveau 
        - quasiment pas de portabilité du code 
        - debogage et détection d'erreurs plus fastidieux 

    - Que va proposer le cours ? 
        - plusieurs architectures (Intel, MIPS, ARM)
        - plusieurs systèmes (GNU/Linux, Windows)
