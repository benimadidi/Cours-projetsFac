Il est l'un des principaux animaux de companie et compte aujourd'hui une cinquantaine de races différentes reconnues par les instances de certification. Dans de très nombreux pays, le chat entre dans le cadre de la légalisation sur les carnivores domestiques à l'instar du chien furet. Essentiellement territorial, le chat est un prédateur de petites proies comme les rongeurs ou les oiseaux. Les chats ont diverses vocalisations dont le ronronnements, les miaulements, les feulements ou les grognements, bine qu'ils communiquent principalement par des positions faciales et corporelles et des phéromones.
